Cómo funciona

  1. Sube tus archivos

    Elige la empresa y el periodo. Usa las plantillas CSV o Excel para cargar compras y RCE.

  2. Revisa las diferencias

    Compara importes por comprobante y registra una observación o confirmación en cada caso.

  3. Consulta el historial

    Vuelve a cualquier mes para revisar las cargas y descargar los archivos originales.

¿Qué formato deben tener los archivos?

Las plantillas de Yupana incluyen las ocho columnas requeridas. Si tu exportación del RCE viene con otras columnas, adapta el archivo antes de subirlo. Se admiten importes desde cero.

¿Necesito mi clave SOL?

Solo necesitas tu cuenta de Yupana. Descarga la propuesta RCE desde SUNAT y súbela al periodo correspondiente.
